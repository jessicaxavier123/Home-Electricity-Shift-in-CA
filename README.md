# Home-Electricity-Shift-in-CA


## Core Research Question

If gas space and water heating in single family homes in California were replaced by heat pumps,
how would the CO2 emission, electricity usage, and winter peak demand change? 

## Scope
1. First, look at California detached homes and then add other types
2. Using a baseline versus one or two heat pump changes
3. Metrics:
    - Annual Electricity (kWh)
    - Annual Gas Usage (__)
    - Winter Evening Peak Demand (kW)
    - Average Hourly Load Profile
    - Annual CO2 
4. Emissions use the long run marginal emission rate so it shows future usage.

## Method

Compare the NREL's baseline data to one or two heat pump upgrades and then price the emissions
with hourly grid data.
